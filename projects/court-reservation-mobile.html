About The Project

Court Reservation Mobile เป็นแอปพลิเคชันบนมือถือที่พัฒนาขึ้นเพื่อแก้ปัญหาความยุ่งยากและความล่าช้าในการโทรจองสนามกีฬาแบบดั้งเดิม โดยเปลี่ยนประสบการณ์ให้ผู้ใช้งานสามารถเช็คตารางเวลาว่างและกดจองสนามได้ทันทีแบบเรียลไทม์ นอกจากนี้ยังเสริมฟีเจอร์ Party ที่ช่วยให้ผู้เล่นสามารถสร้างปาร์ตี้เพื่อหาเพื่อนร่วมเล่นกีฬาได้อย่างสะดวกสบายในแอปเดียว

Key Features

  • Real-time Court Availability Check
  • Booking & Payment System
  • Find Friends / Party System
  • User Notification System

Tech Stack

  • React Native (Expo)
  • Node.js
  • MySQL Database
  • Express.js
  • Android Studio
  • Tailwind CSS
