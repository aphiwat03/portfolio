Deep Dive

About The Project

โปรเจกต์นี้เน้นการพัฒนาระบบและปรับปรุงประสบการณ์ผู้ใช้งาน (UX/UI) สำหรับแพลตฟอร์มภายในองค์กร โดยรับผิดชอบใน 2 ส่วนหลัก ได้แก่
1. การพัฒนาระบบบริหารจัดการผลการปฏิบัติงาน (Performance Management System - PMS) ในโมดูล Performance Management System, Portfolio Management
2. การรีดีไซน์แพลตฟอร์มการเรียนรู้ (Academy Platform) เป้าหมายสำคัญคือการยกระดับโครงสร้างพื้นฐานเดิมให้ทันสมัย (Modernize) และปรับปรุง Usability เพื่อให้พนักงานใช้งานระบบดิจิทัลขององค์กรได้ง่ายและมีประสิทธิภาพสูงสุด

Key Features

  • • Performance Dashboard: ออกแบบหน้าการประเมินพนักงาน และ แดชบอร์ดสรุปผลการดำเนินงานรายไตรมาส
  • • Employee Portfolio: หน้าจัดการข้อมูลพนักงานแบบครบวงจร (ประวัติการทำงาน, การโยกย้ายตำแหน่ง, ฐานเงินเดือน, สมาชิกทีม และประวัติการเรียน)
  • • Academy UI Redesign: ปรับโฉมแพลตฟอร์มการเรียนรู้ภายในองค์กรให้ทันสมัยและใช้งานง่ายขึ้น
  • • Responsive Web Prototype: สร้างต้นแบบหน้าเว็บ (Prototype) ที่รองรับการแสดงผลทุกขนาดหน้าจอ

Challenges / Lessons Learned
