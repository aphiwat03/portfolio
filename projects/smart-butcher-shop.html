About The Project

เว็บแอปพลิเคชันอีคอมเมิร์ซเฉพาะทาง (Niche Market) สำหรับจำหน่ายเนื้อสัตว์ โดดเด่นด้วยระบบ AI Chatbot อัจฉริยะที่ช่วยแนะนำส่วนของเนื้อตามงบประมาณได้ทันทีผ่านแชท รองรับการสั่งซื้อตามปกติ พร้อมระบบหลังบ้าน (Admin/Seller) และ Dashboard สรุปยอดขายแบบครบวงจร

Key Features

  • •AI Conversational Commerce: แชทบอทอัจฉริยะแนะนำส่วนของเนื้อตามงบประมาณ ตอบคำถาม ได้ทันทีในแชท
  • •Hybrid Ordering System: รองรับกระบวนการสั่งซื้อและชำระเงินทั้งรูปแบบปกติ (E-Commerce) และผ่านระบบ การตรวจสอบของแอดมิน
  • •Seller & Order Management: ระบบหลังบ้านสำหรับร้านค้า เพื่อจัดการข้อมูลสินค้า สต็อกเนื้อสัตว์ และติดตามสถานะออเดอร์
  • •Admin Central Dashboard: แดชบอร์ดกลางสำหรับผู้ดูแลระบบ สรุปยอดขาย และ สถิติภาพรวม

Challenges / Lessons Learned

  • •New Backend Stack: เรียนรู้และปรับตัวอย่างรวดเร็วกับเทคโนโลยีที่ไม่เคยใช้งานมาก่อนอย่าง NestJS และ Prisma ORM ในการสร้างระบบหลังบ้านที่มั่นคงและจัดการฐานข้อมูลได้อย่างมีประสิทธิภาพ
  • •Fullstack Integration: พัฒนาทักษะการเชื่อมต่อระบบแบบ End-to-End ตั้งแต่การออกแบบ UI, การเขียน API จนถึงการจัดการ Database ร่วมกับ AI Engine
  • •Deployment & Infrastructure: เผชิญความท้าทายและปัญหาอย่างมากในช่วงแรกของการ Deploy ระบบจริง ทำให้ได้ฝึกฝนทักษะการแก้ปัญหา และเข้าใจกระบวนการนำโปรเจกต์ขึ้น Production มากยิ่งขึ้น
